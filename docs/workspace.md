# 闲鱼工作台

## 页面与接口

- 经营总览：当前账号的商品统计、快照变化和操作记录。
- 账号矩阵：独立保存多账号扫码会话，支持账号备注、连接检查、重新登录和账号切换。
- 私信监听：按账号启停持续轮询，可仅接收、起草后采用，或自动发送明确无需人工确认的文字回复。
- 留言监听：独立的设置、接收记录、回复处理和回执。真实适配器读取自有商品留言，每轮轮转最多 10 件、每件最多 3 页（30 条），首次补收近 24 小时。支持 Multica 生成回复并由当前账号直接提交；与私信共用三种控制方式。
- 会话工作台：历史与分页、文字和图片发送、关联商品、联系人备注、AI 起草后采用。
- 商品管理：商品链接或 ID 导入、详情与指标刷新、备注和标签、复制到本地草稿。
- 发布中心：图片、本地草稿、价格、配送、地点、商品预览、发布确认、AI 描述优化后采用。
- 模型配置：通过 Channel 读取 Multica 路由，按账号设置私信、留言、商品文案用途。
- 任务中心：查看同步、检查、发送和发布的结果。未知结果不自动重试。
- 话术库：本地模板维护，插入消息输入框后由用户发送。

监听间隔为 15–300 秒，第一次开启从当前时刻接收，恢复时保留原水位。
优先读取消息通道最近 50 个会话，并结合网页列表与连接推送补充（上限 50 个），另轮换刷新已保存会话；
历史消息受平台返回范围限制，长时间停机不保证补收完整历史。
监听数据、草稿、素材、模型路由、操作记录按账号隔离，浏览器切换账号不会改变后台监听的执行账号。

没有订单、发货、退款、商品编辑、下架或删除功能。复制商品不会自动重用远程图片，发布需要上传图片。
现有通用 Multica 路由要求人工确认的回复会保留待采用，自动模式不会跳过该标记。

新增接口包括 `/api/accounts`、`/api/models`、`/api/monitoring/dm`、`/api/monitoring/comment`。
浏览器以 `X-Account-ID` 选择操作账号。素材使用带账号参数且要求工作台登录的 URL。
连接器既有 `X-Execution-Account` 与 `expected_account_id` 校验继续保留。

## 操作流程

保留闲鱼现有样式和功能范围，使用流程对照 XHS 工作台：

- 私信和留言页直接选择监听账号，在同页配置回复路由与控制方式，通过“开始监听 / 应用回复配置”和“停止监听”操作。
- “请求批准”逐条确认正文后发送；“帮我批准”自动发送普通回复，特殊事项等待人工处理；“完全放开”由助手自主决定回复或不回复，不请求批准。私信和留言使用相同流程。“启用自动发送”可暂停自动提交，保留监听和人工批准。改变路由或控制方式后，未发送记录会按新策略重新分析。
- 记录每 5 秒自动刷新，每页 10 条；状态筛选、当前页和未应用的设置保持不变。“刷新记录”只读取记录，“停止监听”只停止监听，不应用未保存的回复配置。
- 私信和留言页先显示本地监听状态与记录，Agent 目录独立加载。目录请求缓慢、离线或超时不会阻塞记录展示及停止监听；目录失败提供单独重试按钮，加载成功后才允许选择 Agent 和提交回复配置。切页后丢弃旧目录响应，后台刷新记录不会提前启用配置保存。等待本地记录时显示跟随深浅色主题的文字状态。
- 在私信记录中“查看聊天”打开侧栏，读取当前已保存记录；需要时读取最新记录，或进入既有会话工作台回复。
- 切换账号保留当前功能页。发布中心切换账号后进入该账号的发布页，不携带前一个账号的草稿 ID。未保存的草稿或监听设置在切换、导航和浏览器前进后退时提示保留或放弃。
- 发布中心明确展示发布账号、草稿状态与发布前检查。图片、描述、售价和地点完整后才能预览发布；确认页再次展示账号与发布参数。移除图片也算未保存修改。

## 数据与写入

Flask 提供接口，Waitress 承载服务，SQLite 存储商品、消息缓存、草稿、备注、模板与操作记录。
数据按闲鱼用户 ID 隔离，文件位于 `.local/web/`；已有 `.local/session.json` 自动迁移到 `.local/web/accounts/<账号哈希>/session.json`。
原始文件保留，重启优先使用迁移后更新过的会话，不覆盖新凭据。
图片会验证格式、体积和像素并重新编码，访问需要工作台登录。

真实发送和发布通过后台任务执行，使用请求 ID 去重。超时或结果不确定时标记未知，不自动重试。
发布成功后的详情回查失败不会重新发布。浏览页面和保存本地草稿不会触发真实发送或发布。
操作记录用于排查成功、失败和不确定结果，不应把 HTTP 200 当作业务成功。

工作台使用独立密码、服务端会话、同源写入校验和 HTTPS Cookie。访问密码在首次启动时生成，保存在
`.local/web/admin-password`，会话与数据库文件均不提交到 Git。门户只提供入口，不共享账号登录。

## 部署

生产入口：<https://d.58nft.net:9448/>。后端仅监听 `127.0.0.1:8770`。
`deploy/xianyu-web.service` 运行应用；`deploy/xianyu-proxy.service` 使用独立 Caddy 配置
`deploy/xianyu.caddy` 提供 HTTPS。服务器配置安装在 `/etc/systemd/system/` 和 `/etc/caddy/xianyu.caddy`。

```bash
sudo systemctl restart xianyu-web.service
sudo systemctl status xianyu-web.service xianyu-proxy.service
journalctl -u xianyu-web.service -n 50 --no-pager
```

反向代理使用的公开来源必须与 `--public-origin` 一致。无需重启其他应用或门户即可更新本工作台。

## 页面切换缓存

闲鱼工作台在当前浏览器窗口内保留每个已打开标签的 DOM 和页面状态。切回时恢复筛选、展开项、页面与列表滚动位置、商品草稿和未发送消息；首次打开仍按需加载。缓存不写入磁盘，切换账号通过整页重新载入清空缓存，刷新或离开窗口仍提醒未保存内容。

离开监听页会暂停该页的界面轮询，回到私信 / 留言页立即刷新记录并恢复轮询，后台更新不覆盖未应用的配置。商品列表恢复后后台读取最新数据；成功写入后使其他无未保存内容的页面缓存失效，显式刷新也重新读取数据。每个标签最多保留一页，会话选择与当前草稿地址随页面一起恢复。

浏览器回归：在独立 DemoPlatform 实例上运行 `web/tests/browser/tab_cache.py`，覆盖 DOM 与事件保留、筛选、滚动、监听配置隔离、草稿、未发消息、历史导航与切账号清空。
