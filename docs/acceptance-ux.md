# 闲鱼工作台使用流程验收

日期：2026-10-11。范围：保留现有闲鱼页面风格和业务内容，参考本地 XHS 账号矩阵、私信监听、评论监听、发布中心的操作方式；不新增其他业务模块。

## 对齐结果

| 场景 | 当前操作 |
|---|---|
| 监听账号 | 功能页直接选择账号，切换后留在当前页，其他账号监听继续运行 |
| 启停与设置 | 同页选择回复路由、请求批准 / 帮我批准 / 完全放开；开始监听 / 应用回复配置、停止监听分开 |
| 刷新 | 每 5 秒读取状态和记录，保留未应用设置、筛选条件与分页；手动刷新不改变监听配置 |
| 回复处理 | 展示正文，批准发送时确认账号和收件人；不回复时确认跳过；回执展示为“平台已接收” |
| 查看聊天 | 监听页侧栏查看已有双向记录，可主动读取最新记录、进入会话工作台回复 |
| 商品发布 | 页面选择发布账号，检查图片、描述、售价、地点；确认页核对账号及参数 |
| 未保存内容 | 监听设置、草稿编辑和图片删除均提示未保存；切换账号、导航、浏览器返回可取消或放弃 |
